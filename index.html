How it works

Search YouTube, add tracks to a playlist, then listen on your Yoto. Louis saves the playlist to your account — you link a physical Make Your Own card in the Yoto app.

  1. Search

    Find a song, show, or artist — or paste a YouTube video, playlist, or channel link.

  2. Add

    Drag tracks into a playlist on desktop, or tap Add on a phone. New names the playlist and creates it on Yoto right away.

  3. Listen

    Update saves the audio to Yoto. Reopen, rename, and update playlists you’ve already made.

Features

Paste a whole playlist URL, draw 16×16 icons, trim intros, split long videos — then Update. Same Louis on desktop, Docker, or Home Assistant.

  • Paste a video, playlist, or channel

    Drop a YouTube link into Search. A video or Shorts opens ready to add; a public playlist or channel loads those videos, pre-checked, so you can drag (desktop) or Add (phone) the group together.

  • Covers for every playlist

    New playlists get a generated cover. Open Artwork to generate another, upload, or crop a 5×7 image for Yoto.

  • 16×16 track art

    Set the icon on the player per track: Yoto’s library, yotoicons.com, an upload, or Draw on a pixel canvas.

  • Trim the bits you don’t want

    Scissors on a YouTube track (or a split group) keeps a region of the full source. Waveform and preview live in a flyout on desktop, a tray on a phone.

  • Long videos become parts

    Sources over 55 minutes expand into connected Part 1 / Part 2 slats. Louis downloads once, then splits into legal Yoto chapters. Move or delete the group together.

  • Level new tracks

    When Update downloads YouTube audio, you can normalize those new extracts. Tracks already on the playlist stay as they are.

  • Built for phones too

    Self-host on your LAN and the layout under 600px is Search / Library, an Add drawer, and Menu Update — including every pending playlist at once. Add to Home puts Louis on the home screen.

Installing on macOS

Louis ships as a .dmg, but it is not yet Apple-notarized. macOS will treat it as an app from an unidentified developer. That is expected — not a virus warning about Louis itself. Work through these screens in order.

  1. 1. Find the downloaded disk image

    From GitHub Releases, download the right file for your Mac: Louis-…-arm64.dmg for Apple Silicon, or Louis-…-x64.dmg for Intel. Open your Downloads folder (or wherever the file landed) and double-click the .dmg.

  2. 2. Drag Louis into Applications

    A window opens with Louis.app on the left and Applications on the right. Drag Louis onto Applications and wait for the copy to finish. Then you can eject the disk image (click the eject icon next to it in Finder’s sidebar).

  3. 3. Open Applications → Utilities

    Because Louis is unsigned, a normal double-click may get blocked. We’ll clear macOS’s quarantine flag first. Open the Applications folder, then open the Utilities folder (green circle in the screenshot).

  4. 4. Open Terminal

    Inside Utilities, open Terminal (green circle). A black or white text window appears — that is normal.

  5. 5. Clear the quarantine flag

    Click in the Terminal window, paste or carefully type this exact command, then press Return: 

    xattr -cr /Applications/Louis.app

    Nothing dramatic should print — a new prompt line means it worked. This only removes the “downloaded from the internet” lock; it does not change Louis itself. If you installed Louis somewhere other than Applications, replace the path in that command with the full path to your Louis.app.

  6. 6. Right-click Louis and choose Open

    Go back to Applications, find Louis, then Control-click (or right-click) it — do not double-click yet. Choose Open from the menu. If macOS still asks for confirmation, click Open again. Louis launches and the first-time setup wizard starts.

Still stuck? Confirm you downloaded from the official GitHub Releases page, picked arm64 vs x64 correctly, and that Louis lives at /Applications/Louis.app when you run the Terminal command. After the first successful Open, you can launch Louis normally from Launchpad or Applications.

Installing on Windows

Louis’s Windows installer is a normal .exe, but it is not yet code-signed. Windows and Microsoft Edge will try hard to stop you. That is expected — not a virus warning about Louis itself. Work through these screens in order. When in doubt: never click Delete or Don’t run.

  1. 1. Edge says the file isn’t commonly downloaded

    After you click Louis-Setup-….exe on GitHub, Edge opens Downloads and shows an orange warning. Do not click the trash can. Click the ⋯ (three dots) next to the file, then click Keep.

  2. 2. Edge asks you to trust the file

    A second dialog appears: “Make sure you trust…” with Publisher Unknown. The big blue button is Delete — ignore it. Click the ⋯ next to Delete, then click Keep anyway.

  3. 3. Open the installer

    In Edge Downloads, open Louis-Setup-….exe (click the filename). Windows shows a blue screen: Windows protected your PC. Do not click Don’t run. Click the small More info link under the warning text.

  4. 4. Click Run anyway

    After More info, Windows shows the app name and Publisher: Unknown publisher. That unknown publisher line is why SmartScreen blocked you — unsigned builds look like this. Click Run anyway (still leave Don’t run alone).

  5. 5. Choose who can use Louis

    The Louis Setup window opens. Prefer Only for me (your Windows username). That installs without needing an admin password. Click Next.

  6. 6. Leave the folder alone and Install

    Setup suggests a folder under your user account (something like AppData\Local\Programs\Louis). You do not need to change it. Click Install.

  7. 7. Wait for Installing

    A progress bar appears. Leave this window open until it finishes. Do not close Edge or the Setup window mid-way.

  8. 8. Finish and run Louis

    When you see Completing Louis Setup, leave Run Louis checked and click Finish. Louis opens and the first-time setup wizard starts (Yoto client ID and YouTube API key).

Still stuck? Confirm you downloaded from the official GitHub Releases page (filename starts with Louis-Setup-). Chrome and Firefox use different wording, but the idea is the same: keep the file, then allow Windows to run an unrecognized app.

First-time Desktop Setup

On first launch, Louis walks through a short setup wizard. You need a YouTube Data API key. For Yoto, prefer Louis’s built-in default client — no yoto.dev app required.

  1. Yoto client

    Click Use default client in the wizard (or later under Settings → Advanced). That fills Louis’s bundled public PKCE client ID — the desktop redirect URI is already registered, so you can skip creating an app on yoto.dev.

    Prefer your own client? Create a public (PKCE) app at yoto.dev, register this redirect URI exactly, paste the client ID, and leave the secret empty:

    http://127.0.0.1:4010/api/yoto/auth/callback

  2. YouTube Data API

    Louis needs a Google API key to search YouTube. YouTube login is not required — only an API key.

    1. Open Google Cloud Console and sign in. Create a project (or pick an existing one).

    2. Enable YouTube Data API v3 for that project (click Enable).

    3. Go to Credentials, click Create credentials → API key, copy the key, and paste it into Louis’s setup form. Restricting the key to YouTube Data API v3 is optional but smart.

    Stuck? Google’s YouTube Data API getting started walkthrough covers the same steps.

  3. Let’s go

    With the default client, the wizard skips the OAuth redirect step. Confirm you’re ready and press Let’s go. Louis saves keys locally and restarts. Use Connect to sign in with Yoto in your system browser — then search, arrange, and Update playlists.

FAQ

Straight answers about what Louis is, how it works, and what you need to run it.

What is Louis?

Louis is a desktop (and self-hosted) app that turns YouTube into audio playlists for your Yoto. You search or paste a link, arrange a playlist, then Update — Louis downloads and transcodes. Linking a physical Make Your Own (MYO) card stays in the Yoto app.

Does Louis put audio on the physical card?

No. Louis edits playlists on your Yoto account. Linking a playlist to a physical Make Your Own card happens in the Yoto app, not in Louis.

Can I use Louis on a phone?

The desktop app is macOS and Windows. If you self-host with Docker or Home Assistant on your LAN, the same app has a phone layout (Search / Library / Add to playlist). Add to Home installs it like an app. There is no native iOS or Android download.

What about hour-long videos?

YouTube sources over 55 minutes split into connected Part 1 / Part 2 tracks so they fit Yoto’s chapter limit. Trim first if you only want a region — Louis keeps that slice and re-splits only if it is still too long.

Can I set the icons on the player?

Yes. The Track Art Editor sets a 16×16 icon per track from the Yoto icon library, yotoicons.com, an upload, or a pixel Draw canvas. If icon save is denied, reconnect Yoto so Louis can request the user:icons:manage scope.

Can I run Louis in Home Assistant?

Yes. Add https://github.com/stuartromanek/louis as a Supervisor add-on repository, install Louis, and open http://homeassistant.local:4000. Do not use Home Assistant ingress — it breaks Yoto sign-in. Options: add-on docs.

What do I need before I start?

A Mac or Windows PC (or Docker / Home Assistant), a Yoto account, a free YouTube Data API v3 key from Google Cloud, and — for Yoto sign-in — either Louis’s Use default client button or your own public PKCE client from yoto.dev.

Is Louis free? Who is it for?

Louis is an open-source project you can download and run yourself. Personal use only. You are responsible for complying with YouTube’s Terms of Service and applicable law when downloading audio.

Desktop app or Docker — what’s the difference?

Same Louis experience either way. The desktop app (macOS / Windows) bundles a local server plus yt-dlp and ffmpeg — no Docker required. Prefer containers? Pull the same release from GHCR (ghcr.io/stuartromanek/louis) or install the Home Assistant add-on. Desktop listens on http://127.0.0.1:4010; Docker and Home Assistant typically use port 4000.

Which installer should I download?

macOS Apple Silicon → Louis-…-arm64.dmg. macOS Intel → Louis-…-x64.dmg. Windows → Louis-Setup-….exe. Installers live on each GitHub Release (same vX.Y.Z as the Docker image). This site highlights “For you” when it can detect your machine.

Why does macOS or Windows warn me the app is unsafe?

Builds are currently unsigned. Gatekeeper (Mac) and SmartScreen (Windows) warn on first open — that is expected, not a claim that Louis is malware. Follow Installing on macOS or Installing on Windows for the exact clicks (including the Terminal xattr step on Mac and Edge “Keep anyway” / “Run anyway” on Windows).

What does “Use default client” do?

It’s the easy way to sign Louis into Yoto. Yoto sign-in needs an OAuth client ID — normally you’d create a public app on yoto.dev and paste the ID into Louis. Use default client skips that: Louis fills in its own bundled public client ID, with the desktop redirect URI already registered.

Click it in the first-run setup wizard, or later under Settings → Advanced, before you hit Connect.

Prefer your own app? Create a public (PKCE) client at yoto.dev, register http://127.0.0.1:4010/api/yoto/auth/callback exactly, paste the client ID into Louis, and leave the secret empty.

What are the benefits of a YouTube API key?

You don’t need one to use Louis. Search works without it — Louis falls back to bundled yt-dlp (a bit slower, with no content filtering on typed search).

Add a free YouTube Data API v3 key if you want faster search, moderate safeSearch on typed queries, and optional Search content filtering (none / moderate / strict) under Settings → Advanced. YouTube login is not required — only the API key from Google Cloud. Paste it in the first-time setup wizard or add it later under Settings. See Google’s getting started guide.

How does Connect / Yoto sign-in work?

After setup, Connect opens your system browser (password managers work). You sign in with Yoto there; Louis polls until you’re signed in. Close the browser tab and return to the app. A bad client ID won’t lock you out of Louis — fix it under Settings.

Where does Louis store my keys and files?

On your machine only — not inside the installer as secrets. macOS: ~/Library/Application Support/Louis/. Windows: %APPDATA%\Louis\. You’ll find config.json (API keys / optional cookies path), yoto-session.json (OAuth tokens after Connect), and an audio/ work folder.

Downloads fail with a bot check or age gate — what now?

Open Settings → Advanced and set an optional Netscape cookies.txt path for yt-dlp. Prefer a throwaway Google account; never share or commit that file. Keep Louis updated — releases refresh bundled download tools.

Can I change settings after first launch?

Yes. Settings → Advanced lets you update the Yoto client ID (default vs your own), YouTube API key, and optional cookies path anytime.

Is Louis open source? Who built it?

Yes — code and releases live on GitHub. Louis is an open-source software project from Stuart Romanek, an internet designer and engineer.
